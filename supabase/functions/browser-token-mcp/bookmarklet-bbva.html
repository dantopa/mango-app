📋 Instrucciones de uso

  1. Configurá los campos de arriba con la URL de tu Edge Function y el refresh secret que configuraste en las variables de entorno de Supabase.
  2. Hacé clic en "Generar Bookmarklet" para crear el enlace personalizado.
  3. Arrastrá el botón verde ("📤 Enviar Token BBVA") a tu barra de favoritos/marcadores.
  4. Logueate en online.bbva.com.ar normalmente con tu usuario y contraseña.
  5. Abrí DevTools (F12 o Cmd+Opt+I) y andá a la pestaña Network. Hacé cualquier navegación dentro del home banking y buscá el header tsec en cualquiera de las requests XHR. Copiá ese valor.
  6. Hacé clic en el bookmarklet desde la barra de favoritos mientras estás en online.bbva.com.ar. El script va a extraer las cookies UId y XSRF-TOKEN automáticamente. Para el tsec, primero intentará leerlo del sessionStorage; si no lo encuentra, te va a pedir que lo pegues desde DevTools.
  7. Confirmá el resultado: vas a ver una alerta indicando si el token se envió correctamente o si hubo un error.
💡 Tip para encontrar el tsec: En DevTools → Network, filtrá por XHR/Fetch. Hacé clic en cualquier request a apis.bbva.com y buscá el header tsec en "Request Headers". Es un string largo alfanumérico.
⚠️ Importante: El bookmarklet solo funciona cuando estás logueado en online.bbva.com.ar. Si la sesión expiró, volvé a loguearte antes de ejecutarlo. El token se envía cifrado y se almacena en Supabase Vault.

🔍 ¿Qué hace el bookmarklet?

  1. Verifica que estés en online.bbva.com.ar.
  2. Lee la cookie UId para obtener el identificador de usuario.
  3. Lee la cookie XSRF-TOKEN para el token anti-CSRF.
  4. Busca el valor tsec en sessionStorage (claves que contengan "tsec"). Si no lo encuentra, te pide que lo pegues manualmente.
  5. Construye un objeto JSON con los 3 valores: {tsec, uid, xsrf_token}.
  6. Envía un POST al endpoint de refresh con el header Authorization: Bearer TU_SECRET.
  7. Muestra una alerta con el resultado (éxito o error).

🛠️ Solución de problemas

  • "No estás en online.bbva.com.ar" → Asegurate de ejecutar el bookmarklet desde la pestaña donde tenés abierto el home banking de BBVA.
  • "No se encontró la cookie UId" → No estás logueado en BBVA o la sesión expiró. Volvé a loguearte.
  • "No se encontró XSRF-TOKEN" → La sesión puede haber expirado. Refrescá la página del home banking.
  • "Se necesita el valor tsec" → El bookmarklet no pudo encontrar el tsec automáticamente. Seguí las instrucciones para copiarlo desde DevTools → Network.
  • "Error 401" → El refresh secret es incorrecto. Revisá la configuración.
  • "Error de red" → Verificá la URL del endpoint y que la Edge Function esté deployeada.

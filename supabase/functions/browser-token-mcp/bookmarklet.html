📋 Instrucciones de uso

  1. Configurá los campos de arriba con la URL de tu Edge Function y el refresh secret que configuraste en las variables de entorno de Supabase.
  2. Hacé clic en "Generar Bookmarklet" para crear el enlace personalizado.
  3. Arrastrá el botón verde ("📤 Enviar Token Nexo") a tu barra de favoritos/marcadores.
  4. Logueate en platform.nexo.com normalmente con tu usuario y contraseña.
  5. Hacé clic en el bookmarklet desde la barra de favoritos mientras estás en platform.nexo.com. El script va a extraer las cookies de sesión y enviarlas al MCP server automáticamente.
  6. Confirmá el resultado: vas a ver una alerta indicando si el token se envió correctamente o si hubo un error.
⚠️ Importante: El bookmarklet solo funciona cuando estás logueado en platform.nexo.com. Si las cookies expiraron, volvé a loguearte antes de ejecutarlo. El token se envía cifrado y se almacena en Supabase Vault.

🔍 ¿Qué hace el bookmarklet?

  1. Lee las cookies JSESSIONID, nsi, esi y nexo_installation_id desde document.cookie.
  2. Construye un objeto JSON con esos valores: {jsessionid, nsi, esi, installation_id}.
  3. Envía un POST al endpoint de refresh con el header Authorization: Bearer TU_SECRET.
  4. Muestra una alerta con el resultado (éxito o error).

🛠️ Solución de problemas

  • "No se encontró JSESSIONID" → No estás logueado en Nexo o la sesión expiró. Volvé a loguearte.
  • "Error 401" → El refresh secret es incorrecto. Revisá la configuración.
  • "Error de red" → Verificá la URL del endpoint y que la Edge Function esté deployeada.
  • "No se encontró nexo_installation_id" → Navegá a alguna página dentro de Nexo para que se genere la cookie.
